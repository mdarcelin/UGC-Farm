# UGC Agent Farm

My control panel for UGC video runs. One self-contained page (index.html) holds my Video Intake Form, my Character Vault for locked characters, solo forms for each of my 5 agents, and a Queue for my runs.

The dashboard itself is only the control panel: intake, vault, queue. It does not browse, generate images, or make videos by itself. The real work happens in chat, from the Run in Chat prompts the dashboard writes for me. Nothing is ever posted automatically - posting always needs my separate approval.

## Pages

- **Home** - explains the farm, the 5 agents, the 7 modes, the Product Presentation rule, and how Run in Chat works.
- **Video Intake Form** - the full farm run form: locked character, Mode, Product Presentation, Topic, Length, product name and link, reference video link, Notes.
- **Character Vault** - locked characters (Character A, B, C...), each reusable as that same character.
- **Solo Agent Forms** - one form per agent, each one producing a clean, ready-to-copy prompt for that agent job.
- **Queue** - every full run and solo job in one list, newest first, with a manual status: queued, working, or done. The status buttons only change the label. They never execute anything.

## The 5 agents

1. **Pinterest Scout** - searches Pinterest (guest view, no sign-in) for outfits and products for the chosen mode and topic, especially products with an Amazon link. Does not check price or availability at this step.
2. **Image Agent** - creates the person and avatar images in chat: character references, the outfit photo, and the outfit reference sheet. All ultra realistic, all PNG, all 9:16.
3. **Story Agent** - writes the hook, the shots, and the script. Scene action only in video prompts, never a description of the character.
4. **Video Agent** - makes the video in chat with the Consistent Character workflow and returns it in chat for my approval. Never posts it.
5. **Caption Agent** - writes the TikTok caption, on-screen hook, and hashtags. No price, discount, or sale claim unless a live price was actually verified.

## The 7 modes

A mode is a setting, not a separate farm. It changes the Pinterest search, the story structure, the shots, and the captions.

1. Get Ready With Me
2. Spend The Day With Me
3. Tutorials in general
4. Makeup tutorials
5. Hair tutorials
6. Product reviews
7. Cooking videos

## Product Presentation

One single choice per run, picked right after Mode: **Wearing the product** OR **Holding the product**. Never both.

- Wearing run: every scene prompt ends "Wearing the product, not holding it."
- Holding run: every scene prompt ends "Holding the product, not wearing it."

## Character Vault rules

- Slot 1: headshot, one photo, 9:16.
- Slot 2: body reference sheet, ONE single 9:16 photo with front, three-quarter, left profile, and right side views of the same person, same outfit, same background, all on that one photo.
- A character is not locked until both slots are filled.
- Uploads are JPG or PNG, kept exactly as saved. Webp is rejected.

## How Run in Chat works

1. Pick the outfit on Pinterest (one with an Amazon link when there is a product) and copy its picture.
2. Lock the outfit in chat: put the locked character in that exact outfit using her reference photos. Check face match and outfit match.
3. Make the outfit reference sheet in chat: one single 9:16 sheet with front, profile, and three-quarter shots of her in that outfit. Save as PNG.
4. Build the video with the Consistent Character lock. Reference One is her headshot (Slot 1). Reference Two is the chat-made outfit reference sheet. Reference Two is never empty. The reference photos are the lock - no character descriptions go into scene prompts.
5. Create the scenes from that lock, in script order, 9:16.
6. Export and return the video in chat for my approval. Never post, publish, or share it.

## Good to know

- The page starts completely empty. I add my own characters and runs.
- Characters, uploads, and runs live on the open page for the session only. Closing or reloading the page clears them, so keep the tab open while working.
- AI-made images are PNG, never webp. My own uploaded Vault photos stay as I saved them (JPG or PNG).
